# TanksBattle

لعبة معركة دبابات أركيد تعمل مباشرة في المتصفح، مستوحاة من ألعاب Battle City مع خرائط قابلة للتدمير، أعداء متعددين، قوى خاصة، ومؤثرات ضوئية وصوتية.

## التشغيل

افتح `index.html` عبر GitHub Pages أو أي خادم ملفات ثابت. لا توجد تبعيات أو خطوات بناء مطلوبة.

## التحكم

- الحركة: الأسهم أو `WASD`.
- الإطلاق: `Space` أو `J`.
- الإيقاف/الاستئناف: `P` أو `Escape`.
- الصوت: زر السماعة أو `M`.
- على الهاتف: لوحة الاتجاهات وزر الإطلاق؛ زرا اليمين واليسار معكوسان حسب طلب التحكم.

## ما الجديد

- خلفية وشارة دبابة جديدتان للهوية البصرية.
- توهج للساحة واللاعب، ماسح ضوئي، مسارات قذائف، انفجارات وجسيمات محسنة.
- كومبو متسلسل يرفع النقاط عند القضاء على الأعداء بسرعة.
- شاشة `Command Deck` بعد كل مرحلة لاختيار تطوير واحد.
- إصلاح منطق نفاد الأرواح وإعادة الظهور، وإيقاف اللعبة تلقائياً عند إخفاء التبويب.

## فحص سريع

```bash
node scripts/smoke-check.mjs
sed -n '/<script>/,/<\/script>/p' index.html | sed '1d;$d' > /tmp/tanksbattle.js
node --check /tmp/tanksbattle.js
git diff --check
```

لخطة التوسع المقترحة، راجع [PLAN.md](PLAN.md). ولتفاصيل البنية والأصول، راجع [STRUCTURE.md](STRUCTURE.md) و[ASSETS.md](ASSETS.md).
